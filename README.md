# Backend – Desafio Técnico SEPLAG MT (Engenheiro de Software Sênior)

Este projeto foi desenvolvido como parte do **processo seletivo da SEPLAG-MT** para o cargo de **Engenheiro de Software Sênior**.

A aplicação implementa uma **API REST** com autenticação JWT, controle de acesso, upload de arquivos, sincronização com API externa.
